# Сайт «Сорбция молекулярных зондов на оксиде графена»

Интерактивный сайт на Streamlit. Он повторяет расчёты ноутбука
`Graphene_unified_analysis_filtered.ipynb` на текущем варианте датасета: любые правки
сразу пересчитывают графики, таблицы, кластеры, прямые RANSAC и метрики на всех вкладках.

## Как пользоваться (для пользователя)

1. **Данные.** Главная вкладка.
   - Таблица редактируется прямо на странице: двойной щелчок по ячейке, ввод, Enter.
     Десятичный разделитель — запятая или точка. Пустая ячейка допустима: такое вещество
     просто не входит в расчёты по этому дескриптору.
   - Флажок «Включено» в каждой строке и список веществ в боковой панели включают и
     выключают вещества. Выключенное вещество остаётся в таблице, но не участвует в расчётах.
   - Кнопки «Включить все», «Выключить все», «Все вещества из Excel», «Как в ноутбуке filtered»
     и кнопки по химическим классам меняют сразу много веществ.
   - «Добавить вещество» и «Добавить дескриптор» — формы под таблицей. Новый дескриптор сразу
     появляется в корреляциях, RANSAC, плоскостях и валидации. Значения можно вставить
     столбцом из Excel.
   - «Отменить последнее изменение», журнал изменений и «Сравнить с исходным Excel» —
     там же.
   - **Изменения живут только в открытой вкладке браузера.** Чтобы их сохранить, нажмите
     «Скачать мой датасет». В следующий раз загрузите этот файл кнопкой
     «Загрузить сохранённый датасет», и всё восстановится.
2. **Кластеризация.** k-средних, иерархическая (с дендрограммой), спектральная, DBSCAN.
   Параметры подбираются автоматически, как в ноутбуке, или задаются вручную. Внизу — сводка
   метрик, ARI, состав кластеров и RANSAC внутри каждого кластера.
3. **Корреляции.** Пирсон и Спирмен, последовательный RANSAC по каждому дескриптору
   с доверительными полосами, RANSAC-плоскости по двум дескрипторам.
4. **Валидация.** Коллинеарность (корреляции, VIF, PCA), вложенная LOO-валидация PLS
   и перестановочные тесты. Тесты запускаются кнопкой «Рассчитать».

Настройки, общие для всех вкладок (единицы сорбции, зерно случайности, параметры RANSAC,
базовый набор дескрипторов), находятся в боковой панели слева. У каждого метода и параметра
есть блок «Что это значит?» с объяснением простыми словами.

## Запуск на своём компьютере

```bash
python3 -m venv .venv-site
.venv-site/bin/pip install -r requirements.txt
.venv-site/bin/streamlit run app.py
```

Сайт откроется по адресу http://localhost:8501.

## Публикация в интернете (Streamlit Community Cloud, бесплатно)

1. Код должен лежать на GitHub: репозиторий `grulyanov/Graphene-Clusterization`,
   ветка `streamlit-site`.
2. Откройте https://share.streamlit.io и войдите через GitHub.
3. Нажмите **Create app** → **Deploy a public app from GitHub**.
4. Укажите: Repository — `grulyanov/Graphene-Clusterization`, Branch — `streamlit-site`,
   Main file path — `app.py`.
5. В **Advanced settings** выберите Python **3.12**.
6. Нажмите **Deploy**. Через несколько минут сайт будет доступен по ссылке вида
   `https://<название>.streamlit.app`, открытой для всех.

Сайт читает `Graphene.xlsx` из репозитория. Если репозиторий публичный, этот файл, включая
листы с сырыми ИК-данными, тоже публичен.

Ресурсы Streamlit Cloud скромные (около 2 ядер, общие для всех посетителей). Расчёты
ускорены (см. ниже), поэтому RANSAC по всем дескрипторам занимает секунды, а
перестановочные тесты с настройками по умолчанию — меньше минуты. Перед запуском тестов
сайт показывает оценку времени.

## Ускорение расчётов

Логика ноутбука не изменена, заменён только «движок» (`analysis.py`, раздел «УСКОРЕНИЕ»):

- `ransac_fit` — точная копия цикла `sklearn.RANSACRegressor.fit` с теми же случайными
  подвыборками, но тысячи проб считаются одной операцией numpy. Последовательность
  подвыборок зависит только от числа веществ, min_samples и зерна, поэтому она
  кэшируется и используется для всех τ;
- `Ols` — та же регрессия, что `LinearRegression`, без дорогих проверок входных данных;
- `loo_q2` — все n LOO-подгонок одновременно;
- лишний параллелизм убран там, где запуск процессов дороже самого расчёта.

| Что | Было | Стало |
|---|---|---|
| RANSAC по 11 дескрипторам (1 ядро) | 51 с | 0,8 с |
| Условный перестановочный тест, 4 × 1000 перестановок | 8,6 с | 0,5 с |
| Полный перестановочный тест, одна перестановка | 2,3 с | 0,02–0,04 с |
| Вложенная LOO-валидация PLS | 1,4 с | 0,3 с |

Совпадение проверено: `python dev/verify.py 1000` (222 из 222 значений ноутбука) и
`python dev/fast_equivalence.py` (1500 случайных наборов: маски точек на прямой идентичны
sklearn). `analysis.USE_FAST = False` возвращает исходные реализации.

## Английская версия

`app_en.py` — английский сайт с тёмно-синей темой и краткими пояснениями. Он **генерируется**
из `app.py` командой `python dev/make_en.py` (переводы — `dev/translations_en.py`, пояснения —
`explain_en.py`). После любой правки `app.py` запустите генератор ещё раз: он покажет новые
непереведённые строки. Описание на английском — `SITE.md`; лицензии — `LICENSE` (код, MIT) и
`LICENSE-DATA.md` (данные, CC BY 4.0); цитирование — `CITATION.cff`, метаданные Zenodo — `.zenodo.json`.

## Что важно знать о данных

- Столбец `Molar Masses, g/mol` в Excel испорчен: почти у всех веществ стоит 102.089.
  Поэтому сайт считает молярную массу по SMILES (RDKit) и из неё переводит сорбцию в г/г.
- У ацетонитрила значение `Sorption, g/g` в Excel (0.540) не равно ммоль/г × M / 1000
  (≈ 0.160). Сайт использует пересчитанное значение. Расхождение видно в «Сравнить с исходным Excel».
- Классов ИК-отклика в Excel нет. Столбец «Класс ИК-отклика» пустой. Когда его заполнят,
  появятся таблицы «кластер × класс ИК» и «класс ИК × на прямой / вне прямой» с критериями
  χ² и Фишера.
- Плотностей в Excel нет. Единицы q·Vm станут доступны, когда плотность будет заполнена
  у всех включённых веществ.
- По SMILES рассчитываются молярная масса и TopoPSA 2D. TPSA 3D (Mordred) и Polar SASA 3D
  зависят от 3D-конформации, их нужно вводить вручную.
